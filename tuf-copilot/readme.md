# tuf-copilot

A Chrome extension that acts as an AI sidekick for solving Data Structures and Algorithms problems on takeUforward (TUF). It provides hints, complexity analysis, and approach breakdowns without spoiling solutions.

## Features

- **Optimal Hints:** Get step-by-step guidance without revealing full solutions immediately.
- **Complexity Breakdown:** Quick insights into time and space complexity tradeoffs.
- **Approach Recommendations:** Suggestions for brute force, better, and optimal approaches.
- **In-Browser Overlay:** Seamlessly integrates with TUF problem pages.
